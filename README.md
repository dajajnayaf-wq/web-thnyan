# مزارع الثنيان — التوت الملكي

موقع ثابت باللغة العربية لعرض منتج «التوت الملكي» من مزارع الثنيان في الكويت. يعمل مباشرة من `index.html` من دون تحويل إلى مسار فرعي، ومحتواه الأساسي لا يعتمد على JavaScript.

## الملفات الحالية

- `index.html`: الصفحة الرئيسية.
- `product.html`: معلومات المنتج.
- `order.html`: طريقة الاستفسار والتحقق قبل الشراء.
- `contact.html`: رابط صفحة التواصل الرسمية فقط.
- `privacy.html` و`terms.html` و`shipping.html`: صفحات الخصوصية والشروط والتوصيل.
- `styles.css` و`app.js`: التنسيق والسلوك الاختياري لقائمة الهاتف والسنة.
- `assets/`: شعار الشركة وصورة التوت بصيغتي WebP للموقع وJPG عمودي 1080×1920.
- `manus-routes.json`: المسارات السبعة المنشورة في المشروع.

حُذفت ملفات التصميمات والمسودات السابقة وصفحات السلة والدفع القديمة. لا توجد قاعدة بيانات أو تسجيل طلب أو دفع إلكتروني أو رفع إيصال أو إرسال رسائل تلقائية في هذا الإصدار. لا تعرض صفحات المشروع رقم هاتف الشركة أو بريدها؛ صفحة التواصل تفتح رابط المتجر الرسمي.

## تشغيل المعاينة

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

افتح `/` لمعاينة الصفحة الرئيسية. الصورة الحالية تمثيلية، لذلك يظهر تحتها الوصف المختصر «صورة تمثيلية». لا يمكن حذف الوصف مع إبقاء صورة مولّدة على أنها تصوير حقيقي؛ لاستبدالها أرسل صورة فعلية معتمدة.

## متطلبات ما قبل حملة فعلية

تفاصيل السعر والعبوة والوزن والتوفر والتوصيل، وانطباق سياسات المتجر المنشورة على التوت، تحتاج اعتماد الشركة. الرابط في المعاينة ليس نطاقاً عاماً للحملة، ولا يضمن أي فحص داخلي قبول سناب شات. راجع `SNAP-ADS.md` و`POLICY-AUDIT.md` و`POLICY-REVIEW.md` للمصادر والقيود.
